# Portfolio — Sebastian Aguilar

Landing de portafolio (HTML, CSS y JavaScript, sin build). GSAP se carga por CDN.

- `info.json`: perfil, About, Skills y contacto.
- `mis-proyectos.json`: los proyectos que se muestran.
- `gestion.html`: CRUD de proyectos; guarda en el navegador y permite exportar un nuevo `mis-proyectos.json`.

## Ver en local
Los JSON se cargan con `fetch`, así que no funciona abriendo `index.html` con doble clic. Usa Live Server (VS Code) o `npx serve`.
